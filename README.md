# RK Tech Solutions — Computer Shop & Repair Center

A premium, production-ready website for RK Tech Solutions, a computer shop and repair center in Piliyandala, Sri Lanka.

## Features

- **15+ Pages**: Home, About, Products, Services (with 11 sub-service pages), Gaming PCs, FAQ, Contact, Privacy Policy, Terms & Conditions, 404, Repair Status Checker, Warranty Checker
- **Premium Design**: Dark theme with blue neon accents, glassmorphism, aurora animations, luxury shadows
- **Animations**: Scroll-triggered reveals, typing effect, animated counters, particle background, floating tech icons, parallax hero, magnetic buttons, custom cursor, page transitions
- **Products**: Filterable/searchable grid with quick-view modal, WhatsApp inquiry, warranty/sale/new badges
- **Services**: 11 service detail pages with features, pricing, and booking CTAs
- **Gaming PCs**: Build tier comparison, pre-built systems, build process showcase
- **Extra Features**: Dark/light mode toggle, floating WhatsApp/call/tools buttons, back-to-top, loading screen, repair status checker, warranty checker, booking form, Google Maps integration
- **SEO**: Meta tags, Open Graph, Twitter Cards, Local Business JSON-LD schema, sitemap.xml, robots.txt, canonical URLs
- **Performance**: Lazy-loaded routes, optimized images (SVG placeholders), minified build
- **Accessibility**: ARIA labels, keyboard navigation, semantic HTML, focus states, high contrast
- **Responsive**: 100% responsive across desktop, laptop, tablet, and mobile

## Tech Stack

- React 18 + TypeScript
- Vite (build tool)
- React Router v6 (routing)
- Tailwind CSS (styling)
- Lucide React (icons)

## Getting Started

```bash
npm install
npm run dev      # Start dev server
npm run build    # Production build
npm run preview  # Preview production build
```

## Project Structure

```
src/
├── components/     # Shared UI components
├── data/          # Site data (products, services, reviews)
├── hooks/         # Custom hooks (theme, reveal, counter)
├── pages/         # Page components
├── utils/         # Utilities
├── App.tsx        # Main app with routing
├── main.tsx       # Entry point
└── index.css      # Global styles + design system
public/
├── favicon.svg
├── manifest.json
├── robots.txt
└── sitemap.xml
```
